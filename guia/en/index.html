Your AI agent: in Meta’s cloud or on the your server?

Meta Muse and OpenMuse (CopilotKit, MIT license) promise the same idea: an agent with its own computer and browser that you can watch work. We compare them point by point and check every claim against primary sources.

View the comparison What was validated
What it is

Two agents, the same central idea

This page brings together claims circulating on social media about Muse and OpenMuse and checks each one against Meta’s official announcement, press coverage, and OpenMuse’s own code on GitHub.

☁️ Meta Muse

Personal agent launched by Meta on Sep 8, 2026. Each user gets a dedicated secure VM in Meta's cloud, with a Chromium browser they can watch and take over. Free, $20, and $100/month plans.

🖥️ OpenMuse

Open-source response from CopilotKit, created on 15/Sep/2026, MIT license. Runs on your server: Expo app (iOS/Android/web), Hono API, browser via Playwright, and Linux computer in Docker, both optional. It’s in alpha.

🔎 This analysis

Most of the claims circulating check out. There are significant errors: the US$ 18 deal billion sometimes appears as “millions,” the database cited as “Pika Light” is PGlite, and OpenMuse does depend on an external service.

User guide · step by step

Run OpenMuse on your machine

Commands taken from the official README (09/28/2026). Since the project is in alpha, check the repository first because the steps may change.

1

Prerequisites

Node 24 LTS, pnpm 11.19.0, and a CopilotKit account, required for the Intelligence key.

node -v              # v24.x
corepack enable && corepack prepare pnpm@11.19.0 --activate
2

Clone and install

Install with the lockfile frozen to reproduce the project’s exact versions.

git clone https://github.com/CopilotKit/OpenMuse.git openmuse
cd openmuse
pnpm install --frozen-lockfile
cp .env.example .env
3

Generate a CopilotKit Intelligence key

This is the step that is often left out. The key stays only on the server, in the .env.

npx copilotkit@latest login
npx copilotkit@latest project select
# paste the generated key into .env:  CPK_INTELLIGENCE_API_KEY=...
4

Start the API and web app

You’ll need two terminals. The sample app runs without a model, a Google account, or Docker.

pnpm dev        # terminal 1: API + task worker
pnpm dev:web    # terminal 2: web interface
5

Try the local demos

Three demos use a test inbox and don’t touch anything real: fill out a trip permission form (generates the PDF and drafts the reply), create a goal that monitors a page, and import sample transactions to see the spending summary.

6

Optional: your own browser and computer

The real browser requires Chromium and a token that protects the connection. The Linux computer runs in Docker.

pnpm dev:browser                 # Playwright/Chromium worker
COMPUTER_ENABLED=true pnpm dev   # connects a Linux computer in Docker
7

Optional: real Gmail and Calendar

In .env: WORKSPACE_MODE=live, OPENMUSE_ACCESS_KEY (24+ random characters) and TOKEN_ENCRYPTION_KEY (32 bytes in base64), plus Google OAuth credentials. Then restart the API.

openssl rand -base64 32   # value for TOKEN_ENCRYPTION_KEY
Verdict

Which one makes sense for you

The conclusion circulating holds up: OpenMuse matches the central idea of Muse, but not yet its polish or reach.

☁️ Choose Muse if…

  • wants to open the app and use it without configuring anything;
  • needs voice, Meta glasses, or real purchases;
  • agrees to give Meta access to email and calendar in exchange for convenience.

🖥️ Choose OpenMuse if…

  • wants the data on their own server;
  • wants to read, change, and extend the code (MIT);
  • is willing to deal with alpha, .env, Docker, and the CopilotKit key.
“Free” doesn’t mean “effortless.” The cost moves from your card to your terminal: hosting, the key for the model you connect, and maintenance of a project that still changes every week.
