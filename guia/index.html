Seu agente de IA: na nuvem da Meta ou no seu servidor?

O Meta Muse e o OpenMuse (CopilotKit, licença MIT) prometem a mesma ideia: um agente com computador e navegador próprios, que você vê trabalhar. Comparamos os dois ponto a ponto e checamos cada afirmação em fonte primária.

Dois agentes, a mesma ideia central

Esta página reúne o que circula nas redes sociais sobre o Muse e o OpenMuse e confere cada afirmação no anúncio oficial da Meta, na cobertura da imprensa e no próprio código do OpenMuse no GitHub.

☁️ Meta Muse

Agente pessoal lançado pela Meta em 8/set/2026. Cada usuário ganha uma VM segura dedicada na nuvem da Meta, com um navegador Chromium que ele pode assistir e assumir. Plano grátis, US$ 20 e US$ 100/mês.

🖥️ OpenMuse

Resposta open source da CopilotKit, criada em 15/set/2026, licença MIT. Roda no seu servidor: app Expo (iOS/Android/web), API Hono, navegador via Playwright e computador Linux em Docker, ambos opcionais. Está em alfa.

🔎 Esta análise

Das afirmações que circulam, a maioria se confirma. Há erros relevantes: o acordo de US$ 18 bilhões aparece às vezes como “milhões”, o banco citado como “Pika Light” é o PGlite, e o OpenMuse depende sim de um serviço externo.

O ponto que quase ninguém menciona: o README do OpenMuse exige uma chave CPK_INTELLIGENCE_API_KEY “em todo modo”, para persistir e reproduzir as conversas. Guia de uso · passo a passo

Rodar o OpenMuse na sua máquina

Comandos tirados do README oficial (28/09/2026). Como o projeto está em alfa, confira o repositório antes, porque os passos podem mudar.

1

Pré-requisitos

Node 24 LTS, pnpm 11.19.0 e uma conta no CopilotKit, necessária para a chave do Intelligence.

node -v              # v24.x
corepack enable && corepack prepare pnpm@11.19.0 --activate
2

Clonar e instalar

Instale com o lockfile travado para reproduzir exatamente as versões do projeto.

git clone https://github.com/CopilotKit/OpenMuse.git openmuse
cd openmuse
pnpm install --frozen-lockfile
cp .env.example .env
3

Gerar a chave do CopilotKit Intelligence

Este é o passo que costuma ser omitido. A chave fica só no servidor, no .env.

npx copilotkit@latest login
npx copilotkit@latest project select
# cole a chave gerada em .env:  CPK_INTELLIGENCE_API_KEY=...
4

Subir a API e o app web

São dois terminais. O app de exemplo roda sem modelo, sem conta Google e sem Docker.

pnpm dev        # terminal 1: API + worker de tarefas
pnpm dev:web    # terminal 2: interface web
5

Testar as demos locais

Três demos usam uma caixa de entrada de teste, sem tocar em nada real: preencher uma autorização de passeio (gera o PDF e rascunha a resposta), criar uma meta que monitora uma página e importar transações de exemplo para ver o resumo de gastos.

6

Opcional: navegador e computador próprios

O navegador real exige Chromium e um token que protege a conexão. O computador Linux roda em Docker.

pnpm dev:browser                 # worker Playwright/Chromium
COMPUTER_ENABLED=true pnpm dev   # liga o computador Linux em Docker
7

Opcional: Gmail e Calendar de verdade

Em .env: WORKSPACE_MODE=live, OPENMUSE_ACCESS_KEY (24+ caracteres aleatórios) e TOKEN_ENCRYPTION_KEY (32 bytes em base64), mais as credenciais OAuth do Google. Depois, reinicie a API.

openssl rand -base64 32   # valor para TOKEN_ENCRYPTION_KEY
Veredito

Qual faz sentido pra você

A conclusão que circula se sustenta: o OpenMuse iguala a ideia central do Muse, mas ainda não o acabamento nem o alcance.

☁️ Escolha o Muse se…

  • quer abrir o app e usar, sem configurar nada;
  • precisa de voz, óculos Meta ou compras de verdade;
  • aceita dar à Meta acesso a e-mail e calendário em troca da conveniência.

🖥️ Escolha o OpenMuse se…

  • quer os dados no seu próprio servidor;
  • quer ler, mudar e estender o código (MIT);
  • topa lidar com alfa, .env, Docker e a chave do CopilotKit.
“Grátis” não quer dizer “sem esforço”. O custo sai do cartão e vai para o terminal: hospedagem, a chave do modelo que você conectar e a manutenção de um projeto que ainda muda toda semana.
