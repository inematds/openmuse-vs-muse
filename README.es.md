## Hallazgos principales

- Se confirma la mayor parte de lo que circula: lanzamiento, VM dedicada, precios (gratis, US$ 20 y US$ 100), novedades de Connect y la stack de OpenMuse.
- El acuerdo de Meta con 29 estados fue de US$ 18 **mil millones**. Hay quienes mencionan “millones”.
- La base de datos mencionada como “Pika Light” es **PGlite**.
- OpenMuse **exige una clave de CopilotKit Intelligence en todos los modos**. Es un servicio externo, ajeno a la licencia MIT, y casi nunca se menciona.
- Cifras del repositorio al 28/09/2026: 2.765★ y 351 forks. Circulan cifras desactualizadas (2.100★ y 230 forks).
